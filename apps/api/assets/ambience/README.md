# Publikljud

Ljuden här läggs ovanpå musiken med reglaget Publiksorl. Båda är fria att använda utan villkor.

| Fil | Källa | Upphovsperson | Licens |
| --- | --- | --- | --- |
| `Folkmassa.ogg` | [211146 unfa another-crowd.flac](https://commons.wikimedia.org/wiki/File:211146_unfa_another-crowd.flac) | unfa | CC0 1.0 |
| `Restaurang.ogg` | [Restaurant ambience.ogg](https://commons.wikimedia.org/wiki/File:Restaurant_ambience.ogg) | stephan (pdsounds.org) | Public domain |

`Folkmassa.ogg` är förstärkt 22,5 dB och omkodad till 44,1 kHz Ogg Vorbis. `Restaurang.ogg` är originalets ljudspår utan ändringar.

Egna ljud läggs i `data/ambience` i repots rot (mp3, ogg, wav, flac eller m4a). De dyker upp i listan Publikljud när sidan laddas om.
